코드 생성 조건 입력

앞의 심층리서치에서 발견한 변화를 관련 상품 카테고리와 키워드로 연결하고, 쇼핑 관심 추이를 확인합니다.

Google AI Studio

심층리서치의 발견 → 관련 상품 조사

백화점 가을 프로모션에 참고하고 싶은 변화 2~3개를 고른 뒤, 그 변화와 연결되는 상품을 찾아보세요. 아래는 조사 주제를 정하는 예시이며, 확인된 트렌드 결론은 아닙니다.

관심이 생긴 경험·변화선택 카테고리상품 키워드 예시
머물고 싶은 공간·집 꾸미기가구/인테리어조명, 러그, 수납장
취향을 표현하는 가을 스타일패션의류 · 패션잡화 중 선택의류: 니트, 가디건 / 잡화: 가방, 스카프
나를 돌보는 체험·셀프케어화장품/미용수분크림, 핸드크림

① 관심 분야의 카테고리·상품 선택 → ② API·조회 조건 입력 후 코드 복사. 첫 화면은 인테리어 상품 예시입니다. 조사 결과는 다음 고객 반응 수집·통합 분석에서 함께 검토하세요.

앞의 심층리서치로 돌아가기 →

🔎 키워드 입력

심층리서치에서 관심이 생긴 인테리어·패션·화장품 등의 카테고리를 고르고, 같은 분야의 상품 키워드 1~5개를 비교합니다.

Step 1 / 2

가구/인테리어는 조명·러그·수납장, 패션의류는 니트·가디건, 화장품/미용은 수분크림·핸드크림처럼 상품명으로 조사하세요. 카테고리를 바꾸면 검색어도 해당 분야에 맞게 직접 바꾸세요. 모든 키워드에 동일 카테고리가 적용됩니다.

🔑 네이버 API 입력

Ncloud 콘솔의 NAVER API HUB에서 발급한 인증 정보를 입력합니다.

버튼을 누르고 수업 비밀번호를 입력하면 공용 Client ID·Secret이 코드에 자동 반영됩니다.

네이버 API 허브 연동

⚙️ 옵션

어제까지의 조회 기간과 일간·주간·월간 집계 단위를 설정합니다.

Step 2 / 2

전체 코드를 Code.gs에 붙여넣고 저장한 뒤 ▶ 실행을 누르세요. 첫 함수 main이 기본 실행 함수이며, onOpen을 수동 실행해도 수집됩니다. 최초 Google 권한 승인이 필요합니다. 이후에는 시트를 새로고침하고 “쇼핑 트렌드 → 전체 데이터 가져오기” 메뉴로 실행할 수 있습니다.

키워드 관심추이 비교표와 각 키워드의 성별·연령별 차트를 수집하고, 쇼핑_실행결과 탭에 성공·실패를 기록합니다.

결과는 쇼핑 클릭량의 상대 지수입니다. 검색수·매출·구매수·성별 구성비를 뜻하지 않으며, 별도 요청의 지수를 직접 비교하지 마세요.
