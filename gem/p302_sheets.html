Part 3. Workspace + AI

Google Sheets에서 AI 함수 사용하기

AI 함수 실습 프롬프트

Google Sheets에서 활용할 수 있는 작업별 AI 프롬프트 예시입니다. 복사하여 스프레드시트에 적용해 보세요.

실습파일
네이버 디벨로퍼
🍽️ 맛집 추천 지정된 지역의 대표 맛집 목록을 요청합니다. (수정 가능)
✍️ 카피 작성 SNS 광고 집행에 알맞은 간결하고 매력적인 한글 문구를 만듭니다. (수정 가능)
🌐 요약 및 번역 외국어 또는 긴 본문 내용을 자연스러운 한국어로 변환합니다. (수정 가능)
📊 정량화: 감성 분류 텍스트 피드백의 감정 톤을 긍정/부정/중립으로 분류합니다. (수정 가능)
⭐ 정량화: 척도 점수화 반응이나 만족도를 1~5점 척도로 정량화합니다. (수정 가능)
🔍 데이터 추출: 계정 ID 이메일 주소에서 @ 앞부분의 사용자 ID만 추출합니다. (수정 가능)
📞 데이터 추출: 연락처 형식 변환 다양한 양식으로 입력된 연락처를 표준 하이픈 형식으로 정규화합니다. (수정 가능)
🏷️ 조건 찾기 수치 조건에 따라 상태 레이블(품절 위험/주문필요/안정)을 동적으로 매핑합니다. (수정 가능)
📂 카테고리 분류 항목을 정해진 소비/업무 카테고리 규격에 맞춰 자동 분류합니다. (수정 가능)

🔑 네이버 API 입력

네이버 개발자센터에서 발급한 인증 정보를 입력합니다.

API KEY

발급받은 API 키는 코드에 포함됩니다. 공유용 코드에서는 키를 별도 관리하는 것을 권장합니다.

🔎 키워드 입력

수집할 키워드 개수를 정하고, 각 검색어를 입력합니다.

KEYWORDS

각 키워드는 별도로 검색한 뒤, 결과 시트의 첫 번째 열에 어떤 키워드의 결과인지 함께 기록됩니다.

⚙️ 검색 옵션

키워드당 출력 개수, 정렬, 검색 대상을 지정합니다.

OPTIONS

뉴스와 블로그는 네이버 검색 API의 서로 다른 엔드포인트를 사용합니다. 선택한 대상에 맞춰 코드가 자동 구성됩니다.

구글 시트 이동

복사한 코드는 Google 스프레드시트의 확장 프로그램 → Apps Script에 붙여 넣어 사용할 수 있습니다.
