Part 5. AI 에이전트

Codex로 만드는 나만의 한 페이지 도구

필요한 기능을 말로 설명하고, HTML 파일을 열어 확인한 뒤 대화로 수정합니다.

예시 프롬프트로 첫 도구를 만들어 봅니다. 결과물은 브라우저에서 열 수 있는 HTML 파일 하나입니다.

Codex에서 실습 폴더를 선택하고 새 대화를 시작하세요. 아래 요청을 복사해 전달합니다.

  1. 실습 폴더의 HTML 파일을 브라우저로 엽니다.
  2. https://workingai.kr 주소를 넣고 QR을 생성합니다.
  3. 휴대폰 카메라로 QR을 스캔해 같은 주소로 연결되는지 확인합니다.
  4. PNG를 다운로드하고, 저장한 이미지도 스캔해 봅니다.

CDN 라이브러리를 사용하는 결과물은 인터넷에 연결한 상태에서 확인하세요.

직접 써 보고 개선할 점 한 가지를 Codex에 요청하세요.

  • 버튼과 글자의 크기
  • QR 이미지의 크기
  • 입력 안내와 오류 메시지

수정된 파일을 다시 열거나 새로고침해서 원하는 대로 바뀌었는지 확인합니다.

이번에는 예시 프롬프트 없이 직접 요청합니다. 작은 기능 하나를 선택하고, 결과물은 한 페이지 HTML로 만드세요.

🎨 컬러코드 추출기

이미지에서 색을 선택하고 HEX·RGB 값을 확인하는 도구

🖼️ 이미지 크기 변환기

이미지의 가로·세로 크기를 바꾸고 저장하는 도구

📝 회의록 정리 양식

직접 입력한 결정 사항과 할 일을 보기 좋게 정리하고 인쇄하는 도구

위 주제 또는 내 업무에서 필요한 도구 하나를 고르세요.

정리한 입력과 결과를 자신의 말로 Codex에 설명하세요.

  • 누가 어떤 상황에서 사용할 도구인지
  • 입력할 내용과 필요한 결과
  • HTML 파일 하나로 저장하고 브라우저에서 실행한다는 조건

처음에는 핵심 기능 하나만 요청하세요. 자동 요약처럼 별도 AI 연결이 필요한 기능은 이번 실습에서 제외합니다.

  • HTML 파일을 열어 실제 데이터를 입력해 봅니다.
  • 입력하지 않았을 때도 확인해 봅니다.
  • 저장·복사·인쇄 등 요청한 기능이 동작하는지 확인합니다.
  • 불편한 점을 설명하고 한 번 이상 수정합니다.
